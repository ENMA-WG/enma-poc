# Sample BIM Data

This PoC uses the Government Building BIM Model (Revit version)
published by the Ministry of Land, Infrastructure, Transport and Tourism
(MLIT), Japan.

Original source:

https://www.mlit.go.jp/gobuild/gobuild_tk6_000132.html

The original BIM model was created with Autodesk Revit 2022.

For this PoC, the Revit model is converted to IFC format and processed
by ENMA-WG for research and demonstration purposes.

The original BIM data and converted IFC files are not distributed in
this repository.

Users should obtain the original BIM data directly from the official
MLIT website and comply with the applicable terms of use.

MLIT website usage policy:

https://www.mlit.go.jp/link.html
