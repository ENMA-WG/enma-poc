# chat_ui

This folder holds the built, static TanStack AI frontend that
`MainWindow.load_chat_ui()` points the embedded `QWebEngineView` at.

It is generated by `chat_ui_src` (the npm project one level up) via
`npm run build` there, which writes straight into this directory
(`vite.config.ts`'s `build.outDir`, with `emptyOutDir: true` - this file
survives that because it lives in `chat_ui_src/public/`, which Vite copies
back into every build). Do not edit files in this directory directly;
edit `chat_ui_src/` and rebuild instead.

`desktop_viewer/server/api_server.py` serves this directory as static files
at `/` on the same local FastAPI server that handles `/chat`, so the page
and the API share an origin. `main()` points `MainWindow.load_chat_ui()` at
that server's URL (`http://127.0.0.1:8756/`), not a `file://` URL.
