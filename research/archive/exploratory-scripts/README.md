# Exploratory Scripts Archive

This directory preserves exploratory scripts created during the ENMA-WG PoC research process.

These scripts are retained as research history and are not part of the current recommended execution workflow.

They document intermediate investigations that contributed to the current implementation in `src/`, including:

- early duct dimension inference from IFC QTO values;
- investigation of dimension calculation errors;
- geometry inspection of selected duct elements;
- spatial diagnostics for duct/space relationships;
- tracing specific pipe connectivity cases;
- an earlier version of duct extraction before system information was incorporated.

## Status

Scripts in this directory may:

- target specific IFC elements or GlobalIds;
- contain dataset-specific assumptions;
- have been superseded by more general tools in `src/`;
- produce outputs that are no longer part of the current workflow.

They are preserved to make the research and validation process traceable.

For current tools and reproducible workflows, use the scripts under `src/`.
